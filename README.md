# Burger Signature & Boutique Stay 🍔🏨

Welcome to the **Burger Signature & Boutique Stay** frontend repository! This is a modern, blazing-fast React application built with Vite and Tailwind CSS. 

This project perfectly harmonizes high-energy American diner maximalism (for the artisanal smash-burger joint) with the tailored, warm intimacy of a Rajasthani boutique hotel in Jaipur.

## 🌟 Features

- **Dual Experience Mode**: Seamlessly switch between the energetic **Cafe/Diner Menu** (`/`) and the elegant **Boutique Suites** booking page (`/hotel`).
- **Retro-Modern Aesthetic**: Features a highly tactile design system with custom vintage typography, solid offset "pop" shadows, and a warm "parchment" canvas instead of clinical digital whites.
- **Fully Responsive**: Carefully crafted layouts that adapt beautifully from mobile devices up to large desktop screens using Tailwind container queries.
- **Zero-Friction UI**: Interactive room selection grids and embedded quick-action WhatsApp booking integrations.

## 🛠️ Technology Stack

- **Framework**: React 18
- **Build Tool**: Vite (Lightning fast HMR and optimized builds)
- **Styling**: Tailwind CSS (v3) + Custom CSS for bespoke animations and clip-paths
- **Routing**: React Router DOM (v6)
- **Typography**: 
  - *Hero/Food Impact*: Bricolage Grotesque, Bungee, Shrikhand
  - *Hospitality/Editorial*: Source Serif 4
  - *Interface/Legibility*: Hanken Grotesk, Plus Jakarta Sans

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

You will need **Node.js** installed on your system (v18 or higher is recommended).

### Installation

1. Open your terminal and navigate into the `app` directory:
   ```bash
   cd app
   ```
2. Install the required NPM dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the local development server with Hot Module Replacement (HMR):
```bash
npm run dev
```
Once running, open `http://localhost:5173` in your browser.
- **`/`** - View the Cafe Menu
- **`/hotel`** - View the Boutique Stay Suites

### Building for Production

To create an optimized production build:
```bash
npm run build
```
The compiled assets will be generated in the `dist` folder. You can preview this build locally using:
```bash
npm run preview
```

## 🎨 Design System Quick Reference
- **Primary Culinary Colors:** Cheddar Amber (`#FFB800`), Brioche Deep (`#1F0D03`), Tomato Crimson (`#E63946`)
- **Hospitality Colors:** Boutique Teal (`#2F88AA`), Parchment Subtle (`#FBF4E8`)
- **Shadows:** Hard offset shadows (`shadow-pop`) to simulate retro diner print materials, and ambient underglows for food photography layers.
