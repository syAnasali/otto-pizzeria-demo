## 🌟 Key Features

### 1. 🍕 Artisanal Neapolitan Pizza Craft
- **Exploded 6-Layer Crust Anatomy**: Interactive exploded breakdown of 48-hr fermented Caputo '00' sourdough, crushed San Marzano D.O.P. tomatoes, molten Fior di Latte mozzarella, 450°C blistered leopard cornicione, sweet Italian basil & cold-pressed EVOO, and warm garlic sourdough knots.
- **Full Artisanal Menu Showcase**: Handcrafted signatures including *Margherita Classica*, *Spicy Diavola Sizzle*, *Wild Truffle & Burrata*, and *Quattro Formaggi*.
- **24/7 Dubai Delivery & Live Villa Catering**: 30-minute express coverage across Nad Al Sheba, Meydan, and Downtown Dubai.

### 2. 🚀 Smooth Motion & Momentum Scrolling (Lenis)
- **Lenis Smooth Scroll Engine**: Momentum-based, buttery-smooth scrolling synchronized with `requestAnimationFrame`.
- **Real-Time Scroll Progress Indicator**: Burnt orange to sun gold gradient progress bar running along the top of the viewport.
- **Scroll-Driven Content Reveals**: High-performance `IntersectionObserver` revealing content gracefully with staggered delays as the user scrolls.

### 3. 💬 Dynamic 6-Review Sliding Carousel
- **Dubai Pizza Aficionados**: 6 verified customer reviews highlighting signature pizzas, live villa catering, and express delivery.
- **Sliding Window Animation**: Smooth multi-card transitions (*Reviews 1,2,3* → *Reviews 2,3,4* → *Reviews 3,4,5* → *Reviews 4,5,6*) with auto-cycling, pause-on-hover, arrow controls, and interactive jump indicators.

### 4. 🗺️ Animated & Interactive Location Hub
- **Nad Al Sheba Map Viewport**: Embedded Google Map styled with custom retro warmth filters.
- **Pulsing Pizza Radar Pin**: Floating live beacon marking the 450°C wood-fired oven.
- **Commute Transit Tags**: Quick distance indicators (`🚆 5m Meydan Track`, `✈️ 15m Downtown/DXB`, `🚗 Free Valet & Parking`) and GPS directions button.
- **Middle-Axis Vertical Alignment**: Symmetrical desktop grid alignment between the left contact/map cards and the right inquiry form.

### 5. 📱 Smooth Mobile Experience
- **Smooth Hamburger-to-Cross Morph**: 3-bar hamburger icon that smoothly rotates and scales into a symmetrical 'X' cross via hardware-accelerated CSS transforms.
- **Accordion Dropdown**: Fluid CSS Grid drawer expansion (`grid-rows-[0fr]` ↔ `grid-rows-[1fr]`) with cascading link entrance animations.

### 6. ✨ Minimalist Pizza-Themed Footer
- **Artisanal Sourdough Canvas**: Warm baked crust gradient (`#FFFDF9` to `#F4E7D5`) with flour-dust micro-dot texturing and ambient hearth glow.
- **Centered Pizza Slice Watermark**: Oversized, tone-on-tone Neapolitan pizza slice illustration in the background layer matching the canvas palette.
- **Continuous Pizza Craft Ticker**: Infinite marquee highlighting 48-hr fermentation, 450°C stone hearth, and Nad Al Sheba location tags.
- **Social Connection Hub**: Tactile interactive pills for **Instagram** (`@ottopizzeria`), **TikTok** (`@ottopizzeria`), **WhatsApp** (`+971 50 378 8009`), and **Google Maps**.

### 7. 🎬 Reload Splash Screen & Card Slide-Out Animation
- **Artisanal Neapolitan Pizza Centerpiece**: Stone hearth ember glow aura, rotating dashed orbit, steaming aroma wisps, bubbly charred crust, molten Fior di Latte mozzarella, pepperoni slices, basil, and a bouncing `🔥 450°C` badge.
- **Interactive Loading Progress**: Live craft phases (*Heating 450°C Hearth...* → *Stretching 48H Sourdough...* → *Fired & Ready! 🍕*) with retro progress bar and percentage counter.
- **Physical Card-Upward Exit**: Smoothly sweeps upwards (`-translate-y-full` with cubic-bezier easing) like a giant artisan pizza box lid lifting off, featuring rounded bottom corners (`rounded-b-[56px]`), retro borders, and depth shadows.

## 🛠️ Technology Stack

- **Framework**: React 18
- **Build Tool**: Vite (Lightning-fast HMR and optimized production bundles)
- **Styling**: Tailwind CSS (v3) + bespoke retro-pop utilities (`retro-border`, `shadow-pop`, custom animations)
- **Smooth Scrolling**: Lenis (`@studio-freight/lenis` / `lenis`)
- **Routing**: React Router DOM (v6)
- **Typography**:
  - *Food/Display*: Shrikhand, Bungee, Bricolage Grotesque
  - *Content/UI*: Plus Jakarta Sans, Hanken Grotesk

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18 or higher recommended)
- **npm** or **pnpm**

### Installation
```bash
# Clone repository or navigate to project directory
cd "otto-pizzeria demo"

# Install NPM dependencies
npm install
```

### Local Development
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### Linting & Code Quality
```bash
npx oxlint
```

### Production Build & Preview
```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
